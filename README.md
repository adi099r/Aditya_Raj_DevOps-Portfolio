# Aditya Raj - Portfolio

React + Vite portfolio, deployed to GitHub Pages.

## Run locally
    npm install
    npm run dev

## Deploy
1. Create a repo (e.g. `adi099r.github.io` or `portfolio`) and push this code to `main`.
2. Repo Settings > Pages > Source: **GitHub Actions**.
3. Every push to `main` builds and publishes the site.

Edit `src/data.js` to change any text, skills or projects.
